# Marks501

Аддон для **World of Warcraft Forever 1.60.1** (Interface `16001`). Помечайте предметы в штатных сумках на продажу и продавайте их вместе с хламом через штатную кнопку торговца.

## Возможности

- Настраиваемая клавиша ставит или снимает метку на предмете под курсором. Метка выглядит как значок мешочка и сохраняется отдельно для каждого персонажа.
- **Sell Junk** добавляет подходящие помеченные стопки к продаже после подтверждения, даже если обычного хлама нет. Сумки, исключённые из продажи хлама, не затрагиваются.
- При открытии торговца аддон показывает количество и стоимость серых предметов. Интерфейс использует язык клиента; для неподдерживаемых языков используется английский.

## Установка

1. Скачайте архив `Marks501-*.zip` со страницы [Releases](https://github.com/Amletov/Marks501/releases) или возьмите папку `Marks501` из исходников.
2. Поместите папку `Marks501` в `_forever_/Interface/AddOns/`. Файл `Marks501.toc` должен лежать непосредственно внутри неё.
3. В настройках клавиш WoW найдите раздел **Marks501** и назначьте свободное сочетание. По умолчанию клавиша не назначена.

## Использование

Наведите курсор на предмет в штатных сумках и нажмите назначенную клавишу. Повторное нажатие снимает метку. Команда `/bm clear` снимает **все** метки текущего персонажа, не продавая и не перемещая предметы.
